# NOIR - Perfume Website

A luxury perfume website with a dark and red theme, built as a frontend practice project.

## Live Demo
https://aditya13832.github.io/Noir-Perfume/

## Features
- Animated landing page with wave effects (GSAP + SVG filters)
- Product page with live cart: quantity, price and total update instantly
- Checkout summary box
- Demo login page (frontend only, no real authentication)
- Responsive layout for desktop and mobile

## Tech Stack
HTML, CSS, JavaScript, GSAP, Bootstrap Icons

## How to run
1. Download or clone this repo
2. Open `index.html` in your browser

## What I learned
- DOM manipulation and event handling
- GSAP timelines and animations
- Responsive design using media queries
- Deploying a project with GitHub Pages
